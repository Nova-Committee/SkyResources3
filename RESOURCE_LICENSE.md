# Resource License Notes

SkyResources3 declares `mod_license=MIT` in `gradle.properties`, and the repository root `LICENSE` applies to new code and documentation created for this NeoForge 1.21.11 migration unless a file states otherwise.

The original SkyResources source project audited for this migration was recorded as All Rights Reserved in `plans/migration-plan.md`. Any texture, model, language, guide, or other asset copied from or derived from that original project should not be assumed to be relicensed under MIT merely because it is present in this repository.

Before a public release that includes legacy-derived assets, the project owner should do one of the following:

- record explicit relicensing permission for those assets;
- keep an appropriate attribution/license note for the legacy-derived assets;
- replace the assets with newly created MIT-compatible resources.

This note is intentionally conservative. It documents the migration boundary; it is not a substitute for a project-owner licensing decision.
